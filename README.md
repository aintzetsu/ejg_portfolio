## Overview

Built with semantic HTML5, modern responsive CSS, and vanilla JavaScript with progressive enhancement:
- **Accessible & Fast**: Works without external frontend dependencies, supports keyboard navigation, `prefers-reduced-motion`, and screen-reader announcements.
- **Interactive CV Modal**: Native `<dialog>` PDF previewer with direct PDF download fallback.
- **Projects Carousel**: Showcases web and desktop systems with button, keyboard (`ArrowLeft` / `ArrowRight`), and touch-swipe support.
- **Flexible Contact Options**: Supports one-click pre-filled Gmail compose or native email client (`mailto:`).
