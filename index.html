Case Study — Simot Sarap Chicken Wings

01 / WEB DEVELOPMENT & DEPLOYMENT

Challenge

Present a local Quezon City wing spot clearly online with fast menu browsing, authentic photography, customer reviews, and accurate branch directions on both mobile and desktop.

Architecture & Stack

Built with React, Tailwind CSS, and reusable UI primitives (Card, Button, Input) featuring instant client-side category filtering across 9 food and drink categories.

Reliability & Branch Integration

Migrated expiring external image URLs to 13 locally bundled high-resolution photos (HTTP 200 served directly from Vercel) and pinned exact Fairview branch coordinates (14.6878125, 121.0920177) in the embedded map.

  • React
  • Tailwind CSS
  • JavaScript
  • Lucide Icons
  • Google Maps Embed
  • Vercel
